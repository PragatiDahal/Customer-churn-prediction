# Customer-churn-prediction
A machine learning project that predicts which telecom customers are likely to cancel their subscription — so the company can act before they leave.
What it does

Explores patterns in customer data (contract type, charges, tenure)
Trains two models: Logistic Regression and Random Forest
Compares their performance and identifies the top factors driving churn

Dataset
IBM Telco Customer Churn — 7,043 customers, 21 features, available on Kaggle.

Tech Stack
Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook
